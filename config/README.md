# Пример критериев

Compose продолжает монтировать существующий корневой `criteria.txt` в
`/app/criteria.txt` только для чтения. Этот каталог содержит только пример и не
монтируется в worker автоматически.

Перенесите согласованные группы из `criteria.example.txt` в корневой
`criteria.txt` и проверьте командой `python -m parking_score validate-criteria`.
Технические ID, hash и версия вычисляются автоматически. Не заменяйте боевой
файл кандидатом до завершения `evaluate --no-publish` и согласования результатов.
